› Cómo empezar

En pie con Docker,
en tres pasos

Clona, levanta y entra. Sin cuentas externas ni instalaciones raras.

Ver instrucciones en el repo →
01

Clona el repositorio

Trae el código a tu máquina o servidor.

terminal
$ git clone https://github.com/HernanCode/MyFiscoGest.git
Cloning into 'MyFiscoGest'…
$ cd MyFiscoGest
✓ listo
02

Levántalo con Docker

Arranca la app y la base de datos MySQL con un solo comando.

terminal
$ docker compose up -d
✔ Container myfiscogest-db-1 Started
$ docker compose exec app php artisan migrate --force
✓ migraciones aplicadas
03

Entra y empieza

Inicia sesión, crea tu año fiscal e invita a quien necesites. El registro público está cerrado.

tu-servidor.com

Aviso importante

Antes de que lo uses, que quede claro

No emite facturas

MyFiscoGest solo registra las facturas que creas fuera y guarda el archivo adjunto.

Los cálculos son orientativos

Los modelos 303 y 130 son estimaciones para organizarte. No sustituyen la presentación oficial ante la AEAT ni son asesoramiento fiscal.

Autoalojado = tú eres el responsable

Si lo despliegas, tú decides el tratamiento de los datos (RGPD y LOPDGDD).

Conservación fiscal

Los registros deben conservarse unos 4 años. Por eso desactivar una cuenta conserva los datos y eliminar es explícito e irreversible.

Software sin garantías

Se ofrece tal cual, para que lo revises y lo adaptes a tu caso.
